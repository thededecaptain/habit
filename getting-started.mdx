You can get a working program live in one sitting: install Habit, start the trial, set your rates, then turn on the storefront pieces.

## Install and start billing

<Steps>
  <Step title="Install the app">
    Open Habit in the Shopify App Store and click **Install**. Review the permissions, then approve.
  </Step>
  <Step title="Start the trial">
    Habit opens in Shopify admin. Go to **Billing** and start the 14-day Standard trial. Admin screens stay locked until a trial or paid plan is active.
  </Step>
</Steps>

Cancel later from **Settings**, not from Billing. See [billing and cancel](/billing).

## Configure your program

Open **Settings** and save when you are done. Habit syncs these values to the storefront widget, cart, and checkout.

### Earning and redeeming

| Setting | What it controls |
|---|---|
| Points earned per $1 spent | Points credited on the **order subtotal** (not tax or shipping), before VIP multipliers |
| Points needed for $1 off | How many points equal $1 of discount |
| Minimum points to redeem | Smallest balance a customer can spend |
| Max % of order payable with points | Cap against the order **subtotal** |

### Referrals

| Setting | What it controls |
|---|---|
| Bonus points for the referrer | Points the existing customer earns when a friend’s first paid order converts |
| Bonus points for the new customer | Points the new customer earns for using a valid code |
| Referral code expiry (days) | How long an unused code stays valid |
| Max active referral codes per member | How many unused codes one customer can hold |
| Alert after this many codes shop-wide | Dashboard banner when code creation volume is high |
| Velocity window (minutes) | Time window for that shop-wide alert |

### Points expiry

Leave **Expire unused points after (days)** blank to keep points indefinitely. If you set a number, the whole balance expires together after that many days with no earn-on-order or redemption. Referral bonuses and manual adjustments do not reset the clock.
