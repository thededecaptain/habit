CREDENTIALS
• Habit is an embedded Shopify app with no separate login — you authenticate via
  Shopify OAuth at install. There is no username or password to provide.
• Install on any development store you control. The 30-day free trial is a TEST
  charge on dev stores (never billed) and unlocks every feature. One flat plan,
  no feature tiers.
• Storefront sign-in uses new customer accounts (passwordless): use any email you
  control and Shopify emails you a 6-digit code.

1. INSTALL
1.1 Install Habit → approve OAuth scopes → you land on the embedded Home.
1.2 Approve Standard ($49 USD / 30 days, 30-day free trial).
1.3 App screens unlock as soon as the trial is active.

2. CHECKOUT EXTENSION
2.1 Add any product → go to checkout.
2.2 "Redeem points" renders under the discount code field automatically — no
    setup required.
    • Signed out: program info + referral code field.
    • Signed in: live points balance + Apply points.
2.3 Optional: Settings → Checkout → Customize → Apps → "redeem-points" to place
    the block somewhere else.

3. CUSTOMER ACCOUNT EXTENSION
3.1 Sign in on the storefront (6-digit email code).
3.2 Profile → "Your rewards" shows the balance and tier progress.
3.3 Orders → rewards announcement banner.
3.4 Optional: Settings → Customer accounts → Configurations → Customize →
    Profile → Apps → "account-rewards".

4. ONLINE STORE
4.1 Habit Home → Setup guide → Open theme editor.
4.2 Add the "Loyalty points" block to the product template (not the header).
4.3 Enable the "Redeem points in cart" app embed.
4.4 Cart redemption works on every plan, including non-Plus stores.

5. PROGRAM SETTINGS
5.1 Habit → Settings. Defaults: 1 point per $1, 100 points = $1 off.
5.2 Change points per dollar, redemption rate, minimum redemption, max share of
    an order, or point expiry → Save → reload to confirm values persist.

6. EARN POINTS
6.1 Signed in on the storefront, place a paid test order (Bogus Gateway).
6.2 Habit → Members: the customer appears with a balance and an EARN ledger row.

7. REDEEM POINTS
7.1 With 100+ points, start a second order.
7.2 Apply points in the cart or at checkout → discount appears on the total.
7.3 Complete the order → Members shows the lower balance and a REDEEM row.

8. REFUND
8.1 Refund that order in Shopify admin.
8.2 Habit reverses the points automatically (REFUND_REVERSAL row). No manual
    clawback needed.

9. VIP TIERS AND REFERRALS
9.1 Habit → Tiers: create a tier with a spend threshold and an earn multiplier.
9.2 Members qualifying by lifetime spend earn at the higher rate.
9.3 Referrals: a member gets a code on the account page; a new customer enters it
    in the cart or at checkout; both sides get bonus points after the order.

10. NOTIFICATIONS
10.1 Habit sends no email. Events go to Shopify Flow (7 triggers) and/or a webhook.
10.2 Settings → Notification webhook URL (https://webhook.site works).
10.3 Place an order → verify the JSON POST: eventName, customerEmail, properties.
10.4 Flow requires Advanced/Plus; the webhook alone is enough to verify this.

11. BILLING AND UNINSTALL
11.1 Settings → Cancel subscription (self-service, no support contact needed).
11.2 Reinstalling and starting a new trial restores existing data.
11.3 Uninstall from the Apps page. GDPR customers/redact, customers/data_request
     and shop/redact webhooks are implemented.
