VERIFY EXTENSIONS FIRST (5.6.1)
————————————————————————
Checkout — “Redeem points”
1. As a buyer, add a product and go to checkout.
2. In the order summary (next to Discount code), confirm the Habit “Redeem points” / “Rewards” UI is visible.
   • Guest: shows a sign-in prompt + referral code field.
   • Signed-in test customer with points: shows balance + Apply points.
3. If it is NOT visible: admin → Settings → Checkout → Customize → Apps → add the
   “Redeem points” block → Save, then reload checkout. (In-checkout extensions
   require checkout extensibility; on non-Plus stores use the cart redeem path below.)

Customer account — “Your rewards”
1. Storefront → log in with the storefront customer above (new customer accounts).
2. Orders (order index) shows a Habit rewards announcement; Profile shows the
   “Your rewards” section with the live balance.
3. If Profile is empty: admin → Settings → Customer accounts → Configurations →
   Customize → Profile → Apps → add “account-rewards” → Save, then reload the
   profile page. (The block auto-places only on a fresh install.)

Cart redeem (works on every plan)
• Storefront → add a product → open the cart → the Habit “Redeem points” embed lets
  the signed-in customer apply points. Enable via Online Store → Themes → Customize →
  App embeds → “Redeem points in cart” if it is off.
