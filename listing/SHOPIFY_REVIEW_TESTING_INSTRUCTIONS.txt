Habit is a loyalty program: customers earn points on orders and redeem them for a discount in the cart or at checkout.

CREDENTIALS
• No separate login — Habit is embedded and authenticates via Shopify OAuth at install. There is no username/password to provide.
• Install on any development store you control. The 30-day trial is a TEST charge (never billed) and unlocks every feature.
• Storefront login uses new customer accounts (passwordless): use any email you control, Shopify sends a 6-digit code.

1. INSTALL
Install Habit → approve OAuth → approve Standard ($49 USD/30 days) with the 30-day free trial. All screens unlock immediately.

2. ACTIVATE THE EXTENSIONS (required first — Shopify requires merchant activation)
Settings → Checkout → Customize, then add each app block and Save:
2.1 Checkout page → "redeem-points" (Shopify Plus only; see step 3).
2.2 Thank you page → "redeem-points" (all plans).
2.3 Profile page → "account-rewards", and Order status page → "account-rewards".

3. CHECKOUT EXTENSION (requires a Shopify Plus store — Shopify limits checkout-step extensions to Plus. On other plans use the cart path in step 6.)
Add a product → go to checkout. "Redeem points" appears in the order summary, under the discount code field.
• Signed out: program info + referral code field.
• Signed in: points balance + Apply points.

4. THANK YOU AND ORDER STATUS (all plans)
After completing an order, the Thank you page shows "You earned N points on this order". The Order status page shows the rewards card.

5. CUSTOMER ACCOUNT EXTENSION
Sign in on the storefront (6-digit code). Profile shows "Your rewards" with the live balance; Orders shows a rewards banner.

6. ONLINE STORE (no activation needed)
Product page shows "Your rewards — Earn N points on this product".
Habit Home → Setup guide → theme editor → enable the "Redeem points in cart" app embed. The cart redeem UI shows for signed-in customers.

7. EARN
Signed in, place a paid test order (Bogus Gateway). Habit → Members: the customer appears with a balance and an EARN row.

8. REDEEM
With 100+ points, start a second order. Apply points in the cart or at checkout → the discount appears on the total → complete the order. Members shows the lower balance and a REDEEM row.

9. REFERRALS
Habit → Referrals → Create a referral code: pick customer A, code FRIEND10 → Create code. Sign in as a new customer B (no prior orders), add a product, open the cart → "Have a referral code?" → FRIEND10 → Apply code → place a paid order. Referrals shows FRIEND10 as Used; Members shows referral bonuses for A and B.

Defaults: 1 point per $1, 100 points = $1 off (Habit → Settings).
Cancel anytime: Habit → Settings → Cancel subscription (self-service).
