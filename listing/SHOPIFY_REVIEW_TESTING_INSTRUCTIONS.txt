CREDENTIALS (4.5.4 / 4.5.5)
————————————————————————
Habit has NO separate login. It is an embedded Shopify app: you authenticate
with Shopify OAuth during install, and every screen lives inside Shopify admin.
There is no Habit username or password to supply.

Install Habit on any development store you control and test it there — the app
is fully self-service and needs no data or setup from us. The 30-day free trial
is created as a TEST charge on development stores, costs nothing, and unlocks
100% of the feature set (there is one flat plan, no feature tiers).

Storefront customer sign-in uses Shopify's NEW CUSTOMER ACCOUNTS, which are
passwordless — sign in with any email you control and Shopify emails a 6-digit
code. No customer password exists for us to provide.

Everything below can be completed end to end on a store you create, using only
your own Shopify login. If anything here does not reproduce, please tell us what
you saw and we will fix it immediately.

1. INSTALL AND START THE TRIAL
————————————————————————
1. Install Habit on your development store and approve the OAuth scopes.
2. You land on the embedded Home with a setup guide.
3. Approve the Standard plan — $49 USD / 30 days with a 30-day free trial.
   On a development store this is a test charge; you are never billed.
   All features unlock immediately; nothing is gated behind the paid period.

————————————————————————
2. VERIFY THE EXTENSIONS (5.6.1)
————————————————————————
Checkout — "Redeem points"
• Add any product, go to checkout, and look at the order summary.
  Habit renders directly under the discount code field, with no setup required.
  - Signed out: rewards panel explaining the program + referral code field.
  - Signed in:  live points balance and an Apply points control.
• It is also available as a checkout block: Settings → Checkout → Customize →
  Apps → "redeem-points", if you want to place it somewhere else.

Customer account — "Your rewards"
• Sign in to the storefront (passwordless code) and open the account pages.
  - Profile:  "Your rewards" section with the live balance and tier progress.
  - Orders:   rewards announcement banner.
• Also available as a block: Settings → Customer accounts → Configurations →
  Customize → Profile → Apps → "account-rewards".

Online store — product page and cart
• Home → setup guide → Open theme editor. Add the "Loyalty points" app block to
  the product template, and enable the "Redeem points in cart" app embed.
• Product page shows what a shopper earns; the cart lets a signed-in member
  apply points. The cart path works on every plan, including non-Plus stores.

3. FEATURE TESTS
————————————————————————
EARN
• Sign in on the storefront, place a paid test order (Bogus Gateway / test mode).
• Habit → Members: the customer appears with a balance and an EARN ledger row.

REDEEM
• With 100+ points, start a second order.
• Apply points in the cart or at checkout → discount appears on the order total.
• Complete the order → Members shows the reduced balance and a REDEEM row.

REFUND
• Refund that order in Shopify admin → Habit reverses the points automatically
  and writes a REFUND_REVERSAL row. No manual clawback needed.

VIP TIERS
• Habit → Tiers → create a tier with a spend threshold and an earn multiplier.
• Members qualifying by lifetime spend move up and earn at the higher rate.

REFERRALS
• A member gets a referral code on the account page; a new customer enters it
  in the cart or at checkout. Both sides receive bonus points after the order.

PROGRAM SETTINGS
• Habit → Settings: points per dollar, redemption rate, minimum redemption,
  maximum share of an order, and point expiry. Save and reload to confirm.

NOTIFICATIONS
• Habit sends no email. Events go to Shopify Flow (7 triggers) and/or a webhook.
• Settings → Notification webhook URL (https://webhook.site works). Place an
  order and confirm the JSON POST: eventName, customerEmail, properties.
• Flow requires Advanced/Plus; the webhook alone is enough to verify this.

4. BILLING AND UNINSTALL
————————————————————————
• Settings → Cancel subscription — self-service, no support contact required.
• Reinstalling and starting a new trial works and restores existing data.
• Uninstall from the Apps page. GDPR customers/redact, customers/data_request
  and shop/redact webhooks are implemented.
