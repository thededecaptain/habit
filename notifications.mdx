title: Notifications

Habit can notify you when customers earn, redeem, refer, change tier, or have points about to expire. Configure this in **Settings → Notifications**.

## Shopify Flow

Habit registers these triggers in Shopify Flow:

- Points earned
- Tier upgraded
- Referral sent
- Referral welcome bonus
- Points redeemed
- Points expiring soon
- Points expired

<Steps>
  <Step title="Open Flow">
    In Shopify admin, go to **Apps → Flow** (install Flow first if needed).
  </Step>
  <Step title="Create a workflow">
    Choose one of Habit's triggers, then add actions — for example send email through Klaviyo, Omnisend, or Shopify Email if those apps are connected to Flow.
  </Step>
  <Step title="Use customer data">
    Each trigger includes the customer reference plus event-specific fields (points, tier name, referral code, etc.).
  </Step>
</Steps>

Flow is the primary path. Merchants pick their own ESP or channel without Habit storing third-party API keys.

## Optional webhook

You can also set **Optional notification webhook URL** in Settings. Habit POSTs JSON with `eventName`, `customerEmail`, and `properties`.

The webhook runs **alongside** Flow — use it for a custom endpoint, Zapier, or internal tooling while Flow handles merchant-facing automations.

Events only send when the member has an email address on file.
