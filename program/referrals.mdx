---
title: Referrals
description: Reward both the referrer and the new customer from the same points ledger, with code limits and velocity alerts.
---

Referrals in Habit use the same points ledger as purchases. You do not install a second app or pay a second fee.

## Set referral bonuses

In **Settings**, configure:

| Setting | What it controls |
|---|---|
| Bonus points for the referrer | Points the existing customer earns when a friend’s first paid order converts |
| Bonus points for the new customer | Welcome points for the new customer |
| Referral code expiry (days) | How long an unused code stays valid |
| Max active referral codes per member | Cap on unused codes one customer can generate |
| Alert after this many codes shop-wide | Dashboard banner when creation volume is high |
| Velocity window (minutes) | Time window for that alert |

## Create and manage codes

Open **Referrals** in the Habit admin to:

- **Create a code** for any customer in your store, including someone who hasn't ordered yet. Choose your own code (for example `FRIEND10`) or leave it blank to generate one, and set how many days it stays valid (blank = never expires). Codes you create don't count toward the per-member limit.
- **See every code** with its referrer, status (Active, Used, Expired, Revoked), who used it, and when it expires. Search by code, name, or email, or filter by status.
- **Revoke** a code so it can no longer be used.

The top of the page shows active codes, successful referrals, and total bonus points awarded.

## How a referral converts

<Steps>
  <Step title="Share a code">
    You create a code in **Referrals**, or a signed-in customer gets one from the storefront widget or the customer account rewards block.
  </Step>
  <Step title="Apply it">
    The new customer enters the code under **Have a referral code?** in the cart (every plan, guests included; needs the **Redeem points in cart** app embed) or, on Shopify Plus, at checkout. The code is checked when they apply it.
  </Step>
  <Step title="First paid order">
    When that customer’s first paid order goes through, Habit credits both bonuses. A customer can redeem only one referral code. Self-referrals are rejected.
  </Step>
</Steps>

Invalid, expired, or already-used codes are ignored at order time. The customer sees the error when they try to apply the code.

The referral field is separate from Shopify's discount code box. A referral code gives bonus points, not a discount, so entering it in the discount box won't work.

## Fraud protection

Habit caps unused codes per member, expires unused codes, and shows a dashboard banner when shop-wide code creation exceeds your velocity threshold.

This will not catch every case, but it stops thousands of codes leaking overnight with no way to notice.
